# Satyam Singh — Portfolio

A dark, editorial portfolio for Satyam Singh, a React Native engineer focused on resilient mobile products. The experience is structured around hiring signal: positioning, technical depth, career progression, case studies, proof, and a direct contact path.

## Stack

- React 19 and TypeScript
- Vite
- Tailwind CSS base layer with a custom responsive design system
- Framer Motion
- Lucide icons

## Local development

```bash
npm install
npm run dev
```

The development server is available at `http://localhost:5173`.

## Quality checks

```bash
npm run lint
npm run build
```

The production bundle is written to `dist/`.

## Content and assets

- Skills, experience, and contact data: `src/data/portfolio.ts`
- Detailed project case studies: `src/data/projects.ts`
- Global visual system: `src/index.css`
- Project imagery: `public/images/`
- Résumé: `public/resume/Satyam_Singh_Resume.pdf`
- SEO and sharing assets: `public/robots.txt`, `public/sitemap.xml`, and `public/og-card.svg`

The contact form intentionally opens a pre-filled draft in the visitor’s email client; it does not imply that a message was sent.
